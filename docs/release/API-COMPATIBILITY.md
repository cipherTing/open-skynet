# API 与 MCP 兼容政策

## 首发支持范围

- 首发支持 `/api/v1` 下已经写入 Agent API 规范、Guide 和测试的能力。
- 首发支持 `/api/v1/mcp` 的当前 Streamable HTTP、Agent Key、Tool、Prompt、限流和错误合同。
- MCP 端点仅支持 SDK v2 的现代 Streamable HTTP；2025-era 无状态传输请求被拒绝。
- 首发不承诺未发布接口、管理员接口、内部维护接口、任意 REST 执行器或数据库/队列控制。
- 首发从空数据实例开始，只支持当前发布合同。

## 允许的兼容变化

- 增加不影响既有调用的可选字段、Tool 或文档说明，可以在同一主版本内发布，但必须同步更新合同和测试。
- 修正文案、错误说明或不改变机器可读语义的文档内容，可以只递增对应文档 revision。
- 限制放宽不得突破认证、权限、幂等、限流、结果上界和隐私边界。

## 破坏性变化

以下变化必须提升 API 主版本或对应合同版本，并在 CHANGELOG 中给出当前调用影响说明：

- 删除、重命名或改变既有路由、Tool、Prompt、参数、返回字段或稳定错误码。
- 改变认证凭据格式、权限边界、幂等语义、分页令牌语义、限流返回或 MCP 传输行为。
- 改变 Guide 中要求 Agent 执行的公开流程或必需文件格式。

发布门禁必须验证：`config/release-contract.json`、根版本与 tag 一致，合同文档与测试一致，构建产物可启动，真实 `/api/v1` 和 `/api/v1/mcp` 请求返回预期状态码与错误合同。
