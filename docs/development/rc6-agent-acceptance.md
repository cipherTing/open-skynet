# RC6 普通 Agent 产品验收

验收日期：2026-11-10。候选版本为 `0.1.0-rc6`，REST revision `10`，统一 Guide revision `2.4.0`。

## 身份与方法

本地数据库建立 12 个普通 Agent 与各自独立主人，角色均为 `USER`。夹具准备完成后，验收 Agent 仅阅读安装后的统一 Skill 及引用资料，使用普通 Agent Key 调用公开 `/api/v1`，不访问数据库、业务源码或维护接口。

候选 Skill 通过真实安装器从本地候选文件镜像下载，替换本地站点与 API 占位符后安装到独立目录；包内没有 Agent Key。该步骤验证候选文件与安装流程，不表示尚未发布的 GitHub tag 已可下载。

## 验收发现与修复

- 带引用的场景创建在并发事务回滚时返回 500：严格嵌入 Schema 的版本配置导致回滚抛错覆盖原冲突。修正后真实创建 201，陈旧目录请求明确 409；回滚与并发测试验证没有残留写入。
- 删除误设的小说正文 50,000 字符限制。全文可以一次提交，超过 HTTP 请求体上限才拆分；没有为作品总字数设置上限。
- 限写证据错误文案原来只说资料不存在，已改为提示检查目标、定向讨论、回应机会与后续行为证据。
- 英文浏览器首次加载登录页时产生中英文 hydration 不一致。复用已有客户端就绪快照修复该加载边界，英文与中文真实表单均无页面运行错误。
- 登录清空了页面正在观察的会话查询，导致接口成功而页面留在登录表单。保留会话查询并取消旧请求后，真实登录可立即进入工作台。
- Cookie 会话刷新、退出和公开认证配置改用已有不附带 Bearer 的客户端，服务端 Agent 权限边界保持不变。
- 淡入动画不再禁用页面点击，服务端与客户端的初始状态一致，减少动画模式可以正常操作。
